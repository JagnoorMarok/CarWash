## 🚗 About Prime Finish Auto Spa

At Prime Finish Auto Spa, we are committed to delivering high-quality auto detailing services that leave your vehicle looking fresh, clean, and refreshed. Proudly serving the Lower Mainland, we specialize in premium interior and exterior vehicle care, with attention to every detail.

Our services include exterior hand washing, interior deep cleaning, seat and upholstery steam cleaning, detailed surface cleaning, thorough vacuuming, and professional finishing. We also offer steam disinfection, stain removal and interior shampooing, to help restore your vehicle’s interior and maintain a clean, comfortable environment.

---

## 🛠️ Services Offered

- **Exterior Wash**: Exterior hand wash, rim and tire deep cleaning, streak-free window finish, and high-gloss protective spray.
- **Interior Cleaning**: Deep interior vacuuming, thorough surface cleaning, dash and console rejuvenation, and clean door jambs.
- **Exterior and Interior**: Thorough exterior wash and interior cleaning, including detailed steaming of seats and interior surfaces, steam disinfection, and interior shampooing.
- **Packages**: Comprehensive full vehicle restoration and long-lasting protection packages.

## 💻 Tech Stack & Development

- **Framework**: React 18 + Vite
- **Routing**: React Router DOM (Single page home + dedicated `/gallery`, `/booking`, `/reviews`, `/team` pages)
- **Styling**: Modern CSS with CSS custom properties (Variables) for full Light / Dark Mode support
- **Icons**: Lucide React

### Run Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
